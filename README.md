# Minha IA — versão local

Esta versão foi feita para você conseguir começar **sem colocar cartão e sem usar uma API paga**.

## O que já funciona
- Chat local
- Memória salva no aparelho
- Entrada por voz (quando o navegador oferece Speech Recognition)
- Resposta falada (TTS)
- Seleção de arquivos de texto, CSV, JSON e HTML
- Galeria/câmera para imagens
- Calculadora simples
- Pesquisa na internet pelo navegador
- Funciona sem internet depois de carregada em um endereço HTTPS compatível com PWA

## Importante
Isto ainda não é um modelo de IA avançado como ChatGPT. As respostas são locais e baseadas em comandos simples. A vantagem é que você pode testar a interface e as funções sem pagar API.

## Como usar no Android
1. Extraia a pasta.
2. Abra `index.html` no navegador para testar.
3. Para instalar como aplicativo/PWA e ter funcionamento offline completo, coloque estes arquivos em uma hospedagem HTTPS. Depois abra no Chrome e use o menu **Adicionar à tela inicial**.
4. Quando você quiser, podemos conectar um cérebro de IA ao mesmo aplicativo sem refazer toda a interface.

Não coloque chaves de API dentro desses arquivos.
